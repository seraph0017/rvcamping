# 需求方测试包适配与上线计划

目标：以 Downloads 的 `Retro-Village-2026-测试包.zip` 为界面与图文基准，接入现有 Hono / SQLite 服务。用户已明确要求完成适配、移动端优化、提交代码和上线。

1. 原样保存需求方图文资源与可维护的页面模板，提取本地 CSS、JS，保持蓝色/珊瑚色/纸白风格；公开首页不展示工作人员入口。
2. `/v/:token` 展示真实家庭资料、本地生成的二维码和服务器核销状态；定时与页面恢复时刷新。`/ops/login` 保持鉴权，扫码打开同一二维码后显示核销台。
3. 保留核销幂等、撤销和冲突机制；补充拍照/图片扫码与 URL 查询，适配当前 HTTP 环境。修复生产 HTTP 会话 Cookie 被标记 Secure 导致登录不保持的问题。
4. 新建 SQLite 留言表，凭有效家庭 token 发布；限制长度、频率，文本安全渲染，管理员可隐藏。各设备读取同一服务端留言列表。
5. 营地地图采用压缩包真实图片，村庄地图展示数据库分区与营位（注明非实测方位），TIPS 使用新版图文。统一轻量过渡、返回历史、滚动位置、小屏/安全区/触控目标和减弱动画设置。
6. 在隔离测试数据库验证：跨设备核销/重复核销/撤销、访客权限、留言持久化/转义/限流、二维码解码、移动布局、所有图片、返回与切屏；运行类型检查和构建。
7. 上线前备份服务器数据库、配置和代码 revision；更新构建、重启专属服务、检查公网与原有站点。保留旧二维码 token 与现有数据。
8. 更新 README 与 Obsidian 项目交接，记录实测证据、部署 revision、剩余外部资料。
